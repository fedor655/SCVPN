# Новый интерфейс SCVPN для macOS

Рабочая ветка `ui/macos-v2`. Состояние работы держится здесь: один тик — один
неотмеченный шаг из чеклиста.

Границы правок: только `desktop/macOS/Sources/SCVPNApp/`. `core-swift/`,
`ios/`, `android/`, `desktop/Windows/`, `desktop/shared/`, `SCVPNHelperKit/` не
трогаем. В частности `core-swift/Sources/SCVPNCore/Theme.swift` сверяется
тестом с `android/app/src/main/res/values/colors.xml` — правка ломает и тесты,
и Android. Новые метрики и производные оттенки объявляются в новом файле
внутри `SCVPNApp`.

## Что есть сейчас

Окно 420×700, скрытая полоса заголовка, светофор опущен в ряд с надписью
«SCVPN». Сверху вниз: шапка → кнопка питания с подписью состояния → заголовок
«СЕРВЕРЫ» → список карточек → блок лога.

Что видно на экране (снято живьём, сборка из `build.sh`):

- **Ритм.** Блок кнопки питания занимает около трети окна, из которых сама
  кнопка — 132 pt, остальное пустота (`.padding(.vertical, 24)` плюс
  фиксированные 32 pt под подстатус). Список серверов при этом зажат, а блок
  лога забирает ещё 130 pt и стоит пустой коробкой, пока ядро не запущено.
- **Одинаковая пластика у всего.** Карточка сервера, блок лога, карточка
  подписки, поле ввода — все `RoundedRectangle(cornerRadius: 10)` с обводкой в
  1 px. Иерархии нет: строка списка весит столько же, сколько панель лога.
- **Выделение слабое.** Выбранный сервер отличается обводкой 1.5 px вместо 1 px
  того же белого. На чёрном фоне разница почти не читается, а имя выбранного
  сервера в этот момент ещё и продублировано в подстатусе.
- **Цифры прыгают.** Аптайм и пинг набраны пропорциональным SF: ширина строки
  меняется на каждой секунде и на каждом замере.
- **Колонка пинга пустует.** Пока не нажали «измерить», справа в каждой строке
  ничего нет, и строки выглядят недоделанными.
- **Движение только одно** — бегущая дуга при подключении. Смена состояния
  происходит мгновенным скачком: кольцо меняет толщину и пунктир без перехода.
- **Цветные эмодзи-флаги** в названиях серверов — единственный цвет в теме,
  которая цвет запрещает намеренно. Флаги приходят из названий подписки, не мы
  их рисуем, но выглядят они как чужая заплата.

## Идея нового

Родственный, не другой: тот же чёрный монохром, тот же знак «S», та же схема
экрана. Меняется вес элементов.

**Один объём на экран.** Сейчас каждый блок обведён рамкой и потому одинаково
тяжёл. В новом варианте объём остаётся ровно у кнопки питания — она главная
вещь в окне. Список серверов становится плоским: строки без карточек и рамок,
разделённые волосяной линией. Выбор показывается не обводкой, а вертикальным
маркером слева и полной яркостью текста (невыбранные — приглушены). Лог из
пустой коробки превращается в одну строку с последним сообщением, которая
раскрывается щелчком.

**Типографика вместо рамок.** Иерархия задаётся размером и яркостью, а не
границами. Все цифры — табличные (`.monospacedDigit`), чтобы аптайм и пинг не
дёргали разметку.

**Состояния получают движение.** Формы состояний остаются прежними (толщина
кольца, пунктир, слова) — это решение доступности, оно не обсуждается. Но
переход между ними анимируется, а простой получает медленное «дыхание» кольца:
окно перестаёт выглядеть замёрзшим.

**Освободившееся место — списку.** Кнопка питания крупнее, а вертикальные
пустоты вокруг неё меньше; список получает больше строк без прокрутки.

Палитра не меняется: те же восемь градаций серого из `Palette`. Новый файл
темы внутри `SCVPNApp` держит только метрики, радиусы, длительности и
производные (прозрачности), но не новые цвета.

## Чеклист

- [x] 1. `Style.swift` в `SCVPNApp/Views/`: метрики, радиусы, толщины,
      шрифтовая шкала. Существующие виды переведены на него без изменения
      внешнего вида — это подложка для остальных шагов.
      Длительности анимаций не заводил: сейчас их некому читать, появятся на
      шаге 4. Шрифты переехали сюда из `Views/Theme+SwiftUI.swift`, файл
      удалён — на главный экран теперь один файл констант, а не два. Шиты не
      трогал, их метрики переезжают на шаге 11.
- [x] 2. Типографика: новая шкала размеров и трекинга, табличные цифры в
      аптайме и пинге. Состояние подключения — 26 pt semibold с отрицательной
      разрядкой, знак в шапке ужат до 12 pt с разрядкой 4, имя сервера стало
      medium. Промежуточных размеров не заводил: шкала — 26 и 10–13, между
      ними пусто. **Вид живьём не проверен: экран был заперт.**
- [x] 3. Шапка: кнопки собраны в одну группу, под шапкой волосяная линия,
      правый край выведен на общую сетку. Группа собрана не рамкой, а
      вплотную: подложки под курсором убраны, светлеет сам знак — рамка в
      шапке спорила бы с кнопкой питания за единственный объём в окне.
      **Вертикаль шапки не тронута** и трогать её нельзя: те же числа
      (`HeaderMetrics`) AppKit использует, чтобы опустить светофор, а тест
      сверяет, что надпись не окажется под кнопками окна.
      **Вид живьём не проверен: экран был заперт.**
- [x] 4. Кнопка питания: 132 → 156, заливка радиальным переходом (свет
      сверху), внутри кольца состояния — тонкая кромка шайбы, в простое кольцо
      медленно дышит яркостью. Форма колец, по которой различаются состояния,
      не тронута. Дыхание крутится на 24 кадрах, а не на `.animation`: окно
      висит открытым часами.
      Пока кнопка выросла, а отступы вокруг неё прежние — блок стал теснее,
      чем нужно; это разбирается на шаге 6.
- [x] 5. Состояния кнопки: переходы idle / connecting / connected / error /
      tunStuck идут растворением за 0.25 с, надпись состояния и подстатус
      меняются тем же переходом. Толщину и пунктир между собой не
      «доанимировали»: пунктир не интерполируется вовсе, а рывок с 3 на 5
      читался бы как подёргивание — поэтому кольца растворяются друг в друга
      целиком. Формы состояний не тронуты.
      **Сами переходы живьём не проверены**: чтобы их увидеть, нужно реальное
      подключение, то есть запуск ядра и демона. Собрано и отрисовано — да,
      но смену состояний надо смотреть отдельно.
- [ ] 6. Блок статуса: заголовок, аптайм табличными цифрами, режим отдельной
      строкой; вертикальные пустоты вокруг блока ужимаются.
- [ ] 7. Список серверов: плоские строки с волосяными разделителями вместо
      карточек, выделение маркером и яркостью.
- [ ] 8. Пинг: колонка постоянной ширины, значение с индикатором, «нет ответа»
      словами; до замера — нейтральный знак вместо пустоты.
- [ ] 9. Пустой список: внятное состояние вместо текста по центру.
- [ ] 10. Лог: свёрнутая строка с последним сообщением, раскрытие щелчком,
      никакой пустой коробки.
- [ ] 11. Шиты (`AddSheet`, `SubscriptionSheet`, `SplitTunnelSheet`,
      `ProgressSheet`) приводятся к новой пластике.
- [ ] 12. Вычитка отступов на всех состояниях, скриншоты «было / стало» и
      список того, что понадобится для переноса на iOS, Android и Windows.

## Заметки на потом

- Цветные эмодзи-флаги в названиях серверов **остаются как есть** — решено
  16.08.2026. Не трогаем ни при отрисовке, ни в названиях.
- Перенос на другие платформы: если новая пластика приживётся, метрики из
  `Style.swift` переезжают в `core-swift/Sources/SCVPNCore/Theme.swift`, и
  тогда же обновляются Android и Windows — иначе тест палитры и сверка с
  `colors.xml` разойдутся.
