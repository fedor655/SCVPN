# Эталонные файлы

Снимок поведения тех реализаций, что уже работают, — чтобы C#-версия не
разъехалась с ними молча. Данные синтетические: UUID, пароли и домены
выдуманы.

## Откуда что взято

| Файл | Источник | Почему именно он |
|---|---|---|
| `links_swift.json` | `core-swift` | парсер ссылок; Swift новее Python и покрыт тестами |
| `subscription_texts_swift.json` | `core-swift` | разбор подписки целиком |
| `links.json`, `subscription_texts.json` | Python | оставлены рядом, чтобы расхождения были видны глазами |
| `xray_configs.json` | Python | **проверено: Swift даёт побайтно то же самое на всех 24 случаях** |
| `singbox_configs.json` | Python | конфиг для Windows; в Swift он свой, macOS-овый (без `interface_name` и `strict_route`) |
| `subscription_info.json` | Python | проверено: совпадает со Swift |
| `labels.json` | Python | проверено: совпадает со Swift |
| `hwid.json` | Python | значение обязано совпасть до символа, иначе у пользователей слетит привязка устройств |
| `profiles.json`, `settings.json` | Python | файлы ровно того вида, что лежат у пользователя на диске |

Пересобрать: `python3 desktop/Windows/tools/make_golden.py`, затем
`swift run` в пакете-дампере (см. историю). После удаления Python-версии
файлы становятся единственным эталоном и правятся только осознанно.

## Осознанные расхождения C# с Python

C#-парсер повторяет Swift, а не Python. Три случая, где они расходятся, —
это исправленные ошибки Python, а не регресс:

1. **`ss-plain-userinfo`** — `ss://method:password@host:port` без base64.
   `base64.b64decode` в Python молча выбрасывает символы вне алфавита
   (`:` и `%`), поэтому «расшифровывает» открытый текст в мусор: метод
   становится двоичной кашей, пароль пустым. Swift и C# на таком входе
   получают отказ декодера и корректно откатываются на открытый текст.
2. **`bad-garbage`** (`vless://` без всего) — Python возвращает сервер с
   пустым адресом, и он попадает в список как строка, к которой нельзя
   подключиться. Swift и C# отвечают «не разобрал».
3. **`vless-no-port`, поле `extra`** — `parse_qs` в Python выбрасывает
   параметры с пустым значением (`sid=`), Swift и C# их сохраняют. На
   работу не влияет, `extra` нужен для отладки и для того, чтобы
   неизвестные параметры пережили круг чтение-запись.

В остальном три реализации обязаны совпадать, и тесты это проверяют.
